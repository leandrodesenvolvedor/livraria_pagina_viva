# Briefing do Projeto – [Nome do Sistema]

## 1. Contexto
# Quem é o cliente?
# R: Sr. Osvaldo, dono da Página Viva.

# O que a empresa/organização faz?
# R: Venda de livros.

# Qual o tamanho da equipe ou do negócio?
# R: Sr. Osvaldo e mais duas funcionárias.

## 2. Problema
# O que não funciona hoje?
# R: O controle de estoque é realizado manualmente em um caderno. As vendas podem deixar de ser registradas, dificultando saber quais livros estão disponíveis. Já ocorreu uma venda de um livro que não estava mais em estoque, causando a necessidade de devolver o dinheiro ao cliente. Os pedidos de livros específicos também são anotados em post-its, que podem ser perdidos.

# Como o processo é feito atualmente, sem o sistema?
# R: Atualmente o controle de estoque é feito em um caderno de forma manual.

## 3. Objetivos
# O que o sistema deve alcançar?
# - Simplificar o controle de estoque
# - registrar entradas e saídas de livros
# - facilitar o acompanhamento das vendas
# - permitir identificar quais livros venderam mais no mês
# - auxiliar na decisão de quais livros devem ser comprados novamente 
# - permitir que as funcionárias utilizem o sistema sem treinamento especializado.

# Qual mudança concreta ele deve provocar na rotina do cliente?
# R: Simplificar o processo de registro de entradas e saidas dos livros.  

## 4. Usuários
# Quem vai usar o sistema?
# R: Sr. Osvaldo e mais duas funcionárias.

# Existem perfis diferentes de usuário, com permissões ou visões diferentes?
# R: Sim, um usuário administrador, e 2 usuários padrão.

## 5. Escopo incluído
# - Cadastro/registro dos livros em estoque;
# - Registro das entradas e saídas de livros;
# - Registro das vendas;
# - Atualização do estoque após as vendas;
# - Consulta dos livros mais vendidos no mês.

## 6. Escopo excluído
# - Funcionalidade sugerida: O sistema avisar os clientes via whatsapp quando chegar um livro que pediram.
# Justificativa: funcionalidade desejada pelo cliente, mas não incluída nesta versão devido à restrição de orçamento.

## 7. Restrições
# - Prazo: O sistema precisa funcionar até o fim do ano por causa das vendas de Natal.
# - Orçamento: Está apertado. 
# - Tecnologia exigida: Não informada
# - Dispositivos compatíveis: O sistema deve funcionar no computador que a livraria já possui no balcão.
# - Qualquer limite conhecido do projeto: O orçamento está apertado e o sistema deve estar funcionando até o fim do ano. 

## 8. Critérios de sucesso
# Como o cliente vai saber que o sistema resolveu o problema?
# R: Verificando, por meio de testes, se o sistema permite realizar corretamente as operações de controle de estoque e vendas previstas.

# Que resultado observável indica sucesso?
# R: As funcionárias conseguem registrar entradas e saídas de livros, estoque é atualizado corretamente após as vendas, é possível consultar a disponibilidade de um livro, é possível identificar os livros mais vendidos no mês, o sistema pode ser utilizado sem treinamento especializado, o sistema funciona no computador existente da livraria.
